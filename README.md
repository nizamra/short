## 📥 Quick Installation

### 🐧 Ubuntu / Linux (Bash)
Installs or updates your `~|/.bashrc` safely using an idempotent script that preserves your existing settings:

```bash
curl -sSL [https://raw.githubusercontent.com/nizamra/short/main/install.sh](https://raw.githubusercontent.com/nizamra/short/main/install.sh) | bash
source ~/.bashrc
